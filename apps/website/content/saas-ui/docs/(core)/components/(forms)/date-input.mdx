## Anatomy

```jsx
import { DateInput } from '@chakra-ui/react'
```

```jsx
<DateInput.Root>
  <DateInput.Label />
  <DateInput.Control>
    <DateInput.Segments />
  </DateInput.Control>
  <DateInput.HiddenInput />
</DateInput.Root>
```

`DateInput.Segments` renders a segment for each part of the date in the order
of the user's locale. Use the arrow keys or type to change a segment. To pick a
date from a calendar instead, use the [Date Picker](/docs/components/date-picker).
