## Usage

By default, `Wrap` applies `display: flex`, `flex-wrap: wrap`, and `gap: 8px` to
its children.

```jsx
import { Wrap, WrapItem } from '@chakra-ui/react'
```

```jsx
<Wrap>
  <div />
  <div />
</Wrap>
```

Pass the `gap` prop to apply a consistent spacing between each child, even if it
wraps.
