Saas UI 3.0 is released. Styled Chakra compositions are now installed as
editable source code from `https://saas-ui.dev/r` via `@saas-ui/cli` on top of
`@saas-ui/chakra-preset`, while `@saas-ui/react` (`3.0.0`) provides unstyled
primitives (`Sidebar`, `Navbar`, `GridList`, `Steps`, and `ErrorBoundary`).

## Highlights

- **`@saas-ui/cli` 3.0.0** — initializes Chakra UI and `@saas-ui/chakra-preset`,
  installs registry items from `https://saas-ui.dev/r`, supports `list`,
  `diff`, `update`, shadcn-compatible registry namespaces, and
  `migrate react-to-registry`.
- **`@saas-ui/chakra-preset` 3.0.0** — supports Chakra UI `^3.38.0`, adds OKLCH
  appearance and semantic palettes, shared control sizes and radii, and recipes
  for `Command`, `DateInput`, `Aside`, `SplitPage`, and 10 Chakra 3.36
  components.
- **Public registry items** — includes `data-table` (TanStack Table v9),
  `filters` (Saas.js Conditions), `modals`, `forms` (TanStack Form),
  `rich-text-editor` (Tiptap), `sidebar`, `navbar`, `app-shell`, `page`,
  `aside`, `split-page`, and `kbd-group`.
- **`@saas-ui/charts` 3.0.0** and **`@saas-ui/appearance` 0.1.0** — Chakra-token
  theming for TanStack Charts and shared OKLCH appearance generators.
