Added slot recipes for 10 new Chakra UI components: Carousel, Code Block,
Color Picker, Date Picker, Floating Panel, Listbox, Marquee, QR Code,
Scroll Area and Tree View. Requires @chakra-ui/react 3.36 or later to use
the new components.

Also fixes two invalid token references in the Tags Input recipe
(`sizes.11` and `durations.normal` do not exist in the preset scale).
