## Anatomy

```tsx
import { RatingGroup } from '@chakra-ui/react'
```

```tsx
<RatingGroup.Root>
  <RatingGroup.Label />
  <RatingGroup.HiddenInput />
  <RatingGroup.Control>
    <RatingGroup.Item>
      <RatingGroup.ItemIndicator />
    </RatingGroup.Item>
  </RatingGroup.Control>
</RatingGroup.Root>
```

If you don't need to customize the rating icons, render `RatingGroup.Control`
without children. It renders the number of rating items specified in the `count`
prop.

```tsx
<RatingGroup.Root count={5} defaultValue={3}>
  <RatingGroup.HiddenInput />
  <RatingGroup.Control />
</RatingGroup.Root>
```
