# Saas UI Shiki themes

`sui-light` and `sui-dark` use CSS variables from the Chakra / Saas UI theme.
Appearance seeds and color mode update highlighting without re-running Shiki.

| Role | Token |
| --- | --- |
| Background | `--chakra-colors-bg-muted` |
| Foreground | `--chakra-colors-fg` |
| Comments / keywords | `--chakra-colors-fg-muted` / `fg-subtle` |
| Tags, functions, operators | `--chakra-colors-accent-solid` |
| Strings | `--chakra-colors-success-solid` |
| Numbers | `--chakra-colors-warning-solid` |
| Errors | `--chakra-colors-destructive-solid` |
